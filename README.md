Saturday 21 November 2026 world news in one image: 50 numbered, sourced
stories across 7 regions and 15 fields — a UTC timeline, KPI strip, 4 hero
stories with flat vector illustrations, 8 illustrated secondary stories, a
world map with numbered pins, an "ALSO ON SATURDAY" one-liner list, and a
DATE CHECK footer that names what was deliberately excluded (and what has
not happened yet). Every story carries a CONFIRMED / REPORTED / CLAIM
confidence mark and its source.

Drawn by a pure standard-library Python program: a hand-written 5x7 bitmap
font, a small raster canvas, and a hand-written PNG encoder. No network,
no third-party packages, fully deterministic — every run writes the same
bytes to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
